Common questions

How do I change a guess?

Tap the code and pick another letter, or use Erase. If the letter is already used, the message above the keyboard names the other code. Select that code to change or erase its guess.

What does a free clue do?

Free clue points to a pattern or a letter. Choose Try it myself to keep solving or Apply clue to fill every tile with that code. If applying it will clear another guess, the clue names that code first.

Where is my progress?

The book button opens the Puzzle journal. Your guesses and completed puzzles are saved on the device you played on. Solving a puzzle unlocks the next one.

Can I play offline?

Yes. The puzzles, free clues, and journal all work offline. Opening a public support or privacy page requires an internet connection.
