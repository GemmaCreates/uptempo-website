How to batch resize and rename photos on iPhone

Set the delivery rules once, run the whole group, and check the files before they leave your phone.

1

Decide what the client needs

Start with the destination. A social post, proofing set, and print delivery may need different image sizes. Ask where the files will be used, then write down the required dimensions, filename style, and delivery format.

2

Group the photos into one job

Create one pack for one client or shoot. Import only the finished photos you plan to deliver. Keeping the batch focused makes the final file count easier to check.

3

Choose the output size

Set the long edge in pixels so portrait and landscape photos follow the same rule without changing their shape. Keep a larger preset for full-size delivery and a smaller preset for previews or quick sharing.

4

Build a clear filename pattern

Use details the recipient will understand, such as the client name, job name, date, and a numbered sequence. Check a preview before export. Make sure the first and last names sort in the right order and no two files share a name.

5

Export the batch to Files

Choose a folder you can find again, then run the batch. Photo Packs prepares JPEG files on the device and saves the completed delivery to Files. Pro can also create a ZIP bundle or PDF contact sheet.

6

Check the delivery before sending

Open the export in Files. Confirm the number of images, inspect the first and last filenames, and open a few photos at full size. Send only after the batch matches the job you promised.

Before export

Quick delivery check

  • Correct photos are in the pack
  • Long-edge size matches the job
  • Filenames sort in order
  • Destination folder is clear
  • Final file count matches
